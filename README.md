# BioQuest — Biología 1

Juego de preguntas basado en el temario de Biología 1 de bachillerato.
Funciona **sin conexión**: abre `index.html` en el navegador.

Repo: https://github.com/S3ebaz/bioquest-biologia-1

## Jugar

1. Descarga el repo o el ZIP.
2. Abre `index.html`.
3. Elige dificultad y número de preguntas.

## GitHub Pages

Settings → Pages → Deploy from a branch → `main` / root.
URL: https://s3ebaz.github.io/bioquest-biologia-1/

## Archivos

- `index.html` interfaz
- `css/style.css` estilos
- `js/questions.js` banco de preguntas
- `js/game.js` lógica
