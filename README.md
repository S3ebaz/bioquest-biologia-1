# BioQuest — Biología 1

Juego de preguntas para estudiar el temario de **Biología 1 (bachillerato)**.

Funciona **sin conexión** y **sin instalar nada**: solo abre `index.html` en el navegador.

**Jugar en GitHub Pages:** [https://s3ebaz.github.io/bioquest-biologia-1/](https://s3ebaz.github.io/bioquest-biologia-1/)

**Repositorio:** [https://github.com/S3ebaz/bioquest-biologia-1](https://github.com/S3ebaz/bioquest-biologia-1)

---

## Características

- 91 preguntas de opción múltiple (unidades 1 a 5)
- Tres dificultades: fácil, medio y difícil + modo mixto
- Preguntas en orden aleatorio
- Pausar y guardar la partida en el navegador
- Explicación cuando te equivocas
- Botón **Ver más del tema** para estudiar
- Pantalla final con porcentaje y temas a repasar

## Cómo jugar en la computadora

1. Entra al repositorio y pulsa **Code → Download ZIP**
2. Descomprime la carpeta
3. Abre `index.html` con Chrome, Edge, Firefox o Safari

No necesitas internet después de descargarlo.

## Publicar con GitHub Pages

1. Repo → **Settings** → **Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` / folder: `/ (root)`
4. Guarda y espera 1–2 minutos
5. Abre `https://s3ebaz.github.io/bioquest-biologia-1/`
